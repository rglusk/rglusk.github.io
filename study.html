Tier Schedule (priority ordering)

Tiers tell you which group to pick on weekends. Tier 1 first, then 2, etc. Multiple weekends per tier — finish a tier before moving on.

Tier 1 · ~6 weeks

Terms that came up in conversation. Component patterns, validation, layout, architecture, versioning, library deep-reads.

Tier 2 · ~4 weeks

React internals — hooks, APIs, reconciliation, rendering models.

Tier 3 · ~5 weeks

Performance — Core Web Vitals, critical path, bundles, browser internals, patterns.

Tier 4 · ~7 weeks

Breadth — TypeScript, a11y, security, networking, testing, tooling, leadership.

Tier 5 · ~7 weeks

Product staff — metrics, experimentation, UX patterns, i18n, analytics, search/data, media, mobile, cross-functional.
